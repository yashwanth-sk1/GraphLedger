## What this project is

GraphLedger is a **working SIH prototype** — not a production system —
that follows the movement of value across banks, crypto exchanges/wallets,
and NFT marketplaces/assets as one unified temporal transaction graph.
It uses deterministic rule-based detection (explicitly NOT a trained ML
model), a weighted explainable risk score, and a local SHA-256
hash-linked ledger. Everything runs locally via Streamlit with no
external services, no real financial data, and no network calls out.

Read `README.md` first for the full feature list (IMPLEMENTED NOW vs.
FUTURE ROADMAP), and `DEMO_NOTES.txt` for how this maps to SIH judging
criteria.

## Module map

| File | Responsibility |
|---|---|
| `app.py` | Streamlit UI only: tabs, filters, sliders, rendering. No detection logic. |
| `analytics.py` | `normalize_transactions`, time/velocity helpers, `TemporalChain`, `find_temporal_chain` / `find_cross_entity_chain`, all `detect_*` rules, `calculate_risk_score`, `run_all_detectors`, `build_velocity_table`. |

| `ledger.py` | `build_ledger`, `verify_ledger` — the tamper-evident hash chain. |
| `generate_data.py` | Synthetic multi-domain dataset generator (bank/crypto/NFT scenarios). |

## Ground rules when modifying this repo

1. **Keep it runnable in one command.** `pip install -r requirements.txt &&
   streamlit run app.py` must always work from a clean checkout. No
   external accounts, API keys, Docker, or database servers.
2. **Never introduce real financial data.** Everything stays synthetic,
   generated by `generate_data.py`. Crypto/NFT prices must stay fixed
   synthetic demo values, clearly labeled — never live market prices.
3. **Don't overstate what's implemented.**
   - The ledger is a "Tamper-Evident / DLT-inspired local ledger
     prototype," never called Hyperledger Fabric or a live blockchain.
   - The detection engine is deterministic rules, never called a trained
     "AI model."
   - NFT alerts stay phrased as "potential" / "pattern signal," never
     confirmed wash trading.
4. **Prefer small, demoable increments** over large half-wired features.
5. **No secrets, no telemetry.**
6. **Preserve backward compatibility** via `normalize_transactions()` —
   an old bank-only CSV must still load without crashing.
7. **Time windows stay configurable**, not hard-coded — add a parameter
   and, where relevant, a slider in `app.py`.

## Before a live demo, smoke-test

1. `python generate_data.py` — no errors, all 9 scenarios reported.
2. `streamlit run app.py` — no tracebacks in the terminal.
3. Overview tab shows non-zero counts across banks/wallets/exchanges/NFTs.
4. Transaction Graph renders with a legend and red (suspicious) nodes.
5. Risk Alerts tab shows alerts across bank, crypto, NFT, and
   cross-ecosystem types.
6. Investigation tab shows velocity numbers for a multi-wallet chain.
7. Ledger Verification: "Build / Verify Ledger" reports a valid chain.
8. Moving a threshold slider changes the alert count.
9. "🚨 Simulate Suspicious Network" adds a new red path and alert.
10. An old bank-only CSV (missing crypto/NFT columns) loads without crashing.
